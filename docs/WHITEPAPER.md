### Goal and audience

Give players a short, repeatable game inside the Greenhouse. The immediate audience is adult arcade players and community event hosts.

### Design and implementation

The original React component runs the timed round. The server route in the inspected website revision returns HTTP 410 for game rewards and labels the game practice mode. The local client holds a session identifier and can reach for a reward endpoint at the end of a qualifying round. Run the public preview on its own origin without a reward service.

### What a contributor can establish

The editable React client compiled and the Start Class button opened a timed round. At the inspected website revision the reward route returns HTTP 410 and describes practice mode. A local score can establish gameplay. An independently verifiable tournament needs authoritative scoring and a way to handle disputed results.
